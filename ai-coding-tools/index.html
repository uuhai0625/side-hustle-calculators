このページは、すでにAI副業に取り組んでいる方向けのコーディングツール料金比較です。まだ始めていない方は、先にAI副業の始め方をご覧ください。

正直な前置き

Claude Code・OpenAI Codex・Cursor・GitHub Copilotは、料金の仕組みがそれぞれバラバラで単純比較ができません。Claude CodeとCodexは単独プランがなく既存のチャットサブスクに含まれる形、Cursorは含まれる利用量を使い切ると従量課金に移行、GitHub Copilotだけが明確な「AIクレジット」制です。しかも肝心のClaude CodeとCodexは、正確な利用回数の上限を公式が意図的に非公開にしています。このページでは、わからないことは「非公開」と正直に書いたうえで、公式に確認できた料金だけを比較表にまとめています。

どんな人に何がおすすめか

  • AI副業を始めたばかり・まずコストを抑えたい人: 各ツールのFreeプランで様子を見るのが最初の一歩です(GitHub Copilot Freeはコード補完2,000回/月、Claude Code・CodexもFreeで一定利用可)。有料化は本当に上限に達してから検討で十分です。
  • エディタでの日常的なコード補完がメインで、たまにAIに質問する程度の人: GitHub Copilot Pro($10/月)が最も安く、コード補完が無制限になる点が大きいです。
  • 副業でサイト・アプリを継続的に作り込む人: Claude Code ProまたはCodex(ChatGPT Plus)クラスが目安です。日常的にエージェントへ実装を任せるスタイルなら、この価格帯からで十分なことが多いです(運営者自身もこの使い方をしています)。
  • 本数・作業量が多く、頻繁に上限に当たる人: Claude Code Max・Cursor Ultra・Copilot Maxのような上位プランを検討してください。ただし高額プランなので、まず下位プランで上限に当たる頻度を確認してからの方が失敗しにくいです。
  • 複数のAIモデルを比較・使い分けたい人: GitHub Copilotが唯一のマルチベンダー型で、Claude・GPT・Gemini・Grok等を切り替えられます。Claude CodeやCodexを試したいがどれか1つに決めたくない場合の選択肢にもなります。
  • すでにVS Code以外の特定IDE(JetBrains等)を使っている人: GitHub Copilotの対応エディタの広さが有利です。Cursorは専用エディタへの移行が必要な点に注意してください。

よくある質問

Claude CodeやOpenAI Codexの利用回数の上限は教えてもらえますか?

いいえ、AnthropicもOpenAIも正確な利用回数の上限は意図的に非公開にしています。どちらも5時間のローリングウィンドウと週次ウィンドウを組み合わせて利用量を管理していますが、「何回まで使えるか」という具体的な数字は公表されていません。実際にどのくらい使えるかは、運営者自身の体感で判断するしかないのが実情です。

GitHub Copilotの無料プランでどこまで使えますか?

GitHub Copilot Freeはコード補完が月2,000回まで利用でき、チャットなど一部機能には別の制限があります。まずコストをかけずに試したい場合の入口として使いやすいプランです。

Cursorの料金体系はどうなっていますか?

Hobby($0)・Pro($20/月)・Pro+($60/月、Proの3倍のエージェント利用上限)・Ultra($200/月、Proの20倍)・Teams($40/ユーザー/月)の5段階です。含まれる利用量を使い切ると、モデルのAPI実費に基づくオンデマンド従量課金にシームレスに移行します。以前あった「◯ドル分」という絶対額の表記は、現在は相対的な倍率表記に変わっています。

GitHub Copilotが他の3ツールと違う点は?

Claude Code・OpenAI Codexは自社モデル専用のCLIエージェント、Cursorは複数モデルを裏側で使うAI特化エディタです。これに対しGitHub Copilotは、Anthropic・OpenAI・Google・xAIなど複数ベンダーのモデルを選べるマルチベンダー型で、Pro以上のプランでは同じAIクレジットプール内でClaude CodeやOpenAI Codexそのものを「外部エージェント」として呼び出すこともできます。

4ツールをそのまま金額だけで比較できますか?

単純比較はおすすめしません。Claude Code・Codexは単独プランがなく既存のチャットサブスクに含まれる形、Cursorは含まれる利用量を使い切ると従量課金、GitHub Copilotは明確なAIクレジット制と、それぞれ料金の仕組みが異なります。このページの比較表や簡易診断は、あくまで目安として使ってください。

4ツールの性質の違い

Claude Code・OpenAI Codex

「どのAIにコードを書かせるか」を選ぶ、CLI中心のエージェント型ツールです。Claude CodeはAnthropicの自社モデルのみ、CodexはOpenAIの自社モデルのみを使用します。どちらも単独プランはなく、既存のチャットサブスク(Claude Pro/Max、ChatGPT Plus/Pro等)に含まれる形で利用します。なお、Anthropicが公開している目安データ(code.claude.com/docs/en/costs)では、エンタープライズ導入全体の平均で開発者1人あたり1日約$13、月$150〜250という数字がありますが、これはAPI従量課金ベースの数字で、Pro/Max定額プランの体感コストとは直接比較できない点に注意してください。

Cursor

AI特化のコードエディタ(IDE)そのものです。複数のAIモデルを裏側で使いますが、Claude CodeやCodexのようなCLIツールではなく、エディタとして独立した製品という位置づけです。

GitHub Copilot

元々はエディタ上のコード補完(オートコンプリート)から始まり、現在はチャット・エージェント・コードレビュー・PR自動作成まで拡張しています。VS Code/Visual Studio/JetBrains/Xcode等、幅広いエディタに対応。Anthropic/OpenAI/Google/xAI等のモデルを選べるマルチベンダー型で、Claude CodeやCodexそのものを内部から呼び出せる唯一のツールです。
